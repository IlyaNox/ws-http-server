# Правила работы в репозитории

- Ветка `main` защищена, изменения только через Pull Request.
- Ветки: `feat/<кратко>`, `fix/<кратко>`, `docs/<кратко>`.
- Каждый PR ревьюит второй участник (минимум один осмысленный комментарий или approve).
- Коммиты — Conventional Commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `perf:`.
- Один PR — одна законченная задача, лучше небольшой.
- Форматирование: `clang-format -i src/*.cpp src/*.hpp`.
- Теги `v0.1`, `v0.2`, `v0.3`, `v1.0` ставим на контрольных точках.
- Задачи ведём в GitHub Issues.
